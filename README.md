# Music Player

A web-based music player built with HTML, CSS and vanilla JavaScript as part of my Web Development internship.

## Features
- Playlist with play, pause, skip and volume control
- Search by title or artist
- Filter songs by category
- Shuffle and repeat
- Add your own songs from your device
- Keyboard shortcuts (Space to play or pause, arrow keys to skip)

## How to run
1. Download or clone this repository.
2. Open `index.html` in Chrome or Edge.
